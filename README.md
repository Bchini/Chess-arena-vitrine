## What you can do

| | |
|---|---|
| 🤖 **Play the computer** | Stockfish 19 at 8 levels, from about 400 to full strength. Take back moves, ask for a hint, watch the evaluation bar. |
| 🔗 **Play a friend online** | Create a game, send the link, play in real time. No account needed. Clocks, draw offers, take-backs, chat, rematch, spectators. |
| 🎓 **Learn with Coach Adel** | 24 interactive lessons in three levels (easy, intermediate, medium), then games where the coach warns you *before* a blunder and explains why. |
| 🧩 **Puzzles** | 242 tactical puzzles checked by Stockfish, in three difficulty levels, with a puzzle rating and a streak. |
| 📈 **Analysis and rating** | After every game, an Elo estimate from your average centipawn loss, an evaluation graph, accuracy, and every mistake marked. |
| 👤 **Your own profile** | Sign in with e-mail (Google coming) to keep your games, rating, progress and settings on every device. |

Plus: premoves, automatic play of forced moves, move confirmation, auto-queen, three piece sets, four board themes, sounds, PGN/FEN import and export, and a full interface in **English, French, Spanish and Arabic** (right-to-left included).

## Built with

React and TypeScript on Cloudflare Workers and Durable Objects (real-time games are refereed on the server), Stockfish 19 compiled to WebAssembly running in your browser, [chess.js](https://github.com/jhlywa/chess.js) and [react-chessboard](https://github.com/Clariity/react-chessboard).

The source code of the application lives in a private repository. This page is its public showcase.
